# Agora-BBS 校园网课堂演示指南

## 1. 演示模式的边界

校园网演示使用 `docker-compose.demo.yml`，与日常开发和生产环境使用不同的 Compose 项目名及数据卷。默认只向宿主机发布 Nginx 的 TCP `8080`：PostgreSQL、Redis、Temporal、Go API 和 Next.js 均只在 Docker 网络内通信，老师和同学无法直接访问这些内部服务。

演示环境采用开发治理门槛：L1/L2/L3 所需有效阅读为 60/180/300 秒，冷静期 60 秒，长文回复区停留 10 秒。每次执行启动脚本都会重复运行安全 Seed，恢复 `demo_l0` 成长旅程并补齐演示账号和文章；不会触碰日常开发环境的数据库卷。

`backend/.env` 是可选的本地配置来源，仅用于提供 LLM 和 SMTP 凭据，仍受 `.gitignore` 保护。Compose 会强制覆盖数据库地址、Redis、Temporal、演示 JWT 和治理门槛，不会把本地数据库连接配置带入演示容器。

## 2. 演示前首次准备

1. 确认 Docker Desktop 数据目录仍位于 D 盘。
2. 在有稳定网络时提前下载镜像并完成一次构建，避免课堂上临时拉取依赖。
3. 如果需要真实 LLM 和 QQ 邮箱验证码，确认 `backend/.env` 已配置；不要展示或提交该文件。
4. 停止可能占用 `8080` 的开发环境：

```powershell
docker-compose -f docker-compose.dev.yml down
```

5. 在项目根目录启动：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\demo-start.ps1
```

脚本会构建镜像、启动服务、等待健康检查、执行迁移、导入 Seed，并打印本机地址和校园网地址。

## 3. 防火墙与校园网访问

先在另一台电脑或手机浏览脚本输出的地址，例如：

```text
http://10.241.248.239:8080
```

IP 地址由校园网动态分配，以上只是示例，每次演示以脚本输出为准。如果本机可以打开、其他设备无法打开，先在管理员 PowerShell 中添加仅允许本地子网访问的防火墙规则：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\demo-firewall.ps1 -Action Enable
```

若仍然无法访问，校园 Wi-Fi 很可能启用了客户端隔离。“连接同一个 Wi-Fi”不等于设备可以互访，应改用手机热点、便携路由器或允许终端互访的有线网络。演示结束后删除防火墙规则：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\demo-firewall.ps1 -Action Disable
```

## 4. 演示账号与推荐流程

| 账号 | 密码 | 用途 |
| --- | --- | --- |
| `admin` | `admin123` | 管理后台与邮箱验证 |
| `demo_admin` | `password` | 备用管理员 |
| `demo_l0` | `password` | 从 L0 开始演示成长 |
| `demo_l1` | `password` | 回复与语境反馈 |
| `demo_l2` | `password` | 结构化发帖与冷静期 |
| `demo_l3_a/b/c` | `password` | 匿名盲审 |

建议按以下顺序演示：

1. 首页、全站模糊搜索、分页和使用说明。
2. 使用 `demo_l0` 展示手册/文章阅读计时与成长中心。
3. 使用 `demo_l1` 展示分层回复和语境反馈。
4. 使用 `demo_l2` 展示结构化发帖、草稿和冷静期。
5. 使用 L3 账号展示匿名盲审。
6. 使用管理员账号完成邮箱校验，展示统计、筛选排序、用户编辑审计、内容治理和 LLM 作业。

管理员真实邮箱验证依赖外网和 SMTP。演示环境属于开发模式，邮件发送成功后，登录页还会同步显示本次演示验证码；生产模式绝不会返回验证码。如果已经配置 SMTP 但校园网阻断了邮件发送，登录请求会失败。此时可临时注释本地 `backend/.env` 中的 `SMTP_*` 配置并重启演示环境，使系统仅使用页面上的开发演示验证码。不要删除授权码文件、不要在投影画面展示其内容，也不要将这种开发行为用于生产环境。

## 5. 演示当天检查清单

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\demo-check.ps1
```

- 使用另一台设备打开校园网 URL，而不是只测试 `localhost`。
- 检查管理员登录、文章列表、API 健康检查和 Temporal 冷静期发布。
- 确认 LLM/SMTP 是否需要外网；准备无外网时的讲解与降级路径。
- 关闭系统自动睡眠，接通电源，暂停会强制重启的系统更新。
- 不在投影画面打开 `backend/.env`、终端环境变量或包含密钥的日志。
- 准备录屏或截图，作为校园网临时故障时的最后备用材料。

## 6. 停止与恢复

停止容器但保留演示数据库：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\demo-stop.ps1
```

再次运行 `demo-start.ps1` 会继续使用演示数据卷，同时重新装载可重复 Seed。不要使用 `docker-compose down -v`，除非已经确认要永久删除独立的演示数据库。

如需仅在本机查看 Temporal UI，可额外运行：

```powershell
docker-compose -f docker-compose.demo.yml --profile ops up -d agora-temporal-ui
```

访问 <http://localhost:8233>。该端口只绑定 `127.0.0.1`，不会向校园网开放。
